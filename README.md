# Seven Scars: playable demo

**Play in your browser:** https://hussainalaradi5.github.io/seven-scars-play/

A fast 2D action brawler demo: combos, a heavy finisher, pistols, dodge, waves, four difficulties, a hidden Blood Moon wave on Hard and Scarred, and three art styles (Comic, Pixel, Noir). It works on desktop (keyboard or gamepad) and on phones in landscape (touch controls).
